# Merge Request Strategy

## Merge Method

The project uses Squash and Merge to keep the develop branch history clean and traceable.

## Rules

- Each Jira ticket should be merged as a single commit.
- Squash commits before merging.
- Source feature branches should be deleted after successful merge.
- Commit titles should reference the Jira ticket ID.

Example:

    - F1-123 Configure MR squash strategy
